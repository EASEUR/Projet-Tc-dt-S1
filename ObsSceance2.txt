Exercice 3 : Défi PR 

Verdict : Request changes
PR fautive : PR #2
Emplacement : Fichier de la requête, sur la ligne avec text(f"SELECT...")
Commentaire : issue (bloquant) : L'utilisation d'une f-string insère l'entrée utilisateur directement dans le SQL. 
Cela crée une faille d'injection SQL qui permet de lire les données utilisateurs comme les mots de passe. 
Il faut utiliser les paramètres liés à la place.
